誰在用？

怎麼用？

【互動邏輯】

把課堂流程寫成清楚的步驟，並寫出不可違反的教學規則。

🧭 操作流程🔒 不可違反的教學規則

例：「答錯第一次給提示1、第二次給提示2、第三次才公布答案」。

出錯怎麼辦？

【防呆機制】

預想學生會怎麼「玩壞」它，事先寫好處理方式。

👆 連按👥 人數錯誤📄 資料空白

心法

教學 APP 開發心法

第一版不完美，是正常的

  1. 生成

    撰寫／貼上指令

  2. 試用

    戴上學生帽子，玩一次

  3. 說出問題

    哪裡卡住、哪裡不順

  4. 修改指令

    用自然語言告訴 AI，調整方向

再回到「生成」，直到可以放心帶進教室

試用時，可以這樣玩
  • 故意答錯、連按、什麼都不填就按下一步
  • 把平板轉成直的、橫的各看一次
  • 站到教室最後面看投影畫面
說出問題的句型
  • 「我按了＿＿，結果＿＿，我希望＿＿。」
  • 例：「我連按兩次開始，結果出現兩個計時器，我希望第一次按下後按鈕就停用。」
原則

優化／修改原則

三大關鍵優化原則

一次只改一件事

改太多，就不知道是哪一句發揮作用。

✗ 「字體放大、換成藍色、再加音效，順便改計分方式。」

✓ 「把所有按鈕的文字放大到 24px。」確認沒問題，再改下一件。

描述精確具體

以具體數據或動作，取代模糊指示。

✗ 「光暈大一點、動畫順一點。」

✓ 「吸氣時光暈直徑放大到面板高度的 2/3，吸氣 4 秒、吐氣 6 秒。」

善用版本分支

從滿意版本開發分支測試，保留原有成果。

✓ 滿意的版本先「儲存離線版」或另存一份 HTML，命名為「v1_可上課版」。

✓ 想嘗試新功能時，從 v1 開新的對話或複本修改；改壞了，隨時回到 v1。

步驟

從程式碼到網址的四個步驟

取得、試玩、嵌入、發布

  1. 取得完整程式碼

    照上方的工具說明生成 APP：Gemini Notebook 用「⋮ → 下載」取得 .html 檔；Gemini Canvas、Claude 則請 AI 輸出「完整的 HTML 程式碼」，從 <!DOCTYPE html> 一路複製到最後的 </html>，一個字都不能少。

    貼到下方的即時預覽試玩區（也可以直接開啟下載的 .html 檔），切換電腦、平板、手機寬度試玩；沒問題再下載成 .html 檔，在平板上實際打開一次。

  3. 嵌入 Google 協作平台

    在協作平台「插入 → 嵌入 → 嵌入程式碼」貼上程式碼。看畫面教學

  4. 發布並分享網址

🔁 要修改 APP？換掉程式碼就好

① 點一下嵌入的框架，按左側的鉛筆（編輯 Edit）。② 把舊程式碼全部刪掉，貼上新的程式碼。③ 按「下一步」→「插入」，再按一次「發布」。

✅ 網址不會改變，不用重新給學生連結。

提醒

嵌入前先注意

避免上課時才發現問題

💡 讓 APP 在協作平台裡更好用
  • 框架太小會出現捲軸，請在編輯模式拉大框架，並用平板實際看一次。
  • APP 更新後，用「✎ 編輯嵌入」換掉程式碼，並再按一次「發布」；網址不變。
⚠️ 嵌入後可能受限的功能
  • 嵌入的程式碼是放在框架（iframe）中執行，「下載成績單」「下載 PDF」「儲存離線版」等下載功能，在部分瀏覽器可能無法使用。
  • 儲存在平板中的資料（例如練習進度），可能因瀏覽器的隱私設定而無法保留。
  • 如果遇到這些情況，可以改把 .html 檔直接分享給學生開啟。

遇到下面的情況，才需要用這段指令

🧐 什麼時候需要？
  • 嵌入協作平台後，APP 的畫面被切掉或出現左右捲軸
  • 按「下載成績單」「下載 PDF」「儲存離線版」沒有反應
  • 跳出的提示視窗沒有出現或被擋住
🛠️ 怎麼用？
  • 回到當初做 APP 的 AI 工具（同一個對話）
  • 按下方「📋 複製這段指令」，貼上送出
  • 拿到新的程式碼後，用上方「✎ 編輯嵌入」換掉程式碼，再按一次「發布」
我要把這個 APP 放到 Google 協作平台（Google Sites）上給學生使用，請幫我修改：
1. 畫面寬度要能自動縮放，不要出現左右捲軸；畫面不要太高（大約 800px 以內），內容太多時可以上下捲動。
2. 提示、確認視窗都直接顯示在網頁裡面，不要跳出瀏覽器的小視窗。
3. 在「下載」相關的按鈕旁邊，加上一個「在新分頁開啟」的按鈕，並顯示提示：「如果按了沒有下載，請先在新分頁開啟這個 APP，再按一次下載。」
4. 改好後，請給我完整的 HTML 程式碼（從 <!DOCTYPE html> 到 </html>），不要省略任何部分。
